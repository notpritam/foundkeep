# The FoundKeep dashboard

Every page here is the real dashboard — its Next components — on a sample
library.

**<a href="/dashboard/?path=/docs/start-here--docs" target="_top">Open the dashboard simulator ↗</a>**
— the toolbar there switches the window (desktop 1440, laptop 1280, iPad, iPhone)
and light or dark. Inside the combined design system these switches are not
available: Storybook does not pass them to a composed section.

- **Current** — today's pages, the baseline every proposal is compared with.
- **Proposals** — variants to choose from, flow by flow.
