# FoundKeep design system

One set of tokens and components for every FoundKeep surface — live, rendered
from the product's own source (`theme.css`, `components.css`, `listbox.js`,
`card-icons.js`, `review.html`, the icons in `dock.js`), never screenshots.

**Try the extension:** [download the dev build](/downloads/foundkeep-extension-dev.zip)
(FoundKeep Dev, syncs to dev.foundkeep.app), or reload the copy kept up to date
in `~/Downloads/foundkeep-extension-dev` on the MacBook.

## How it is organised

- **Foundations** — color, typography, spacing, radius, elevation and
  iconography: the `--fk-*` tokens every component uses.
- **Components** — the building blocks, named by what they are: Badge, Button,
  Card, Listbox, Save preview, Select, Status message, Sync status, Tag, Text
  field, Tooltip. Each has a
  *Playground* (change variant, size and state in Controls), a *Variants*
  overview, *In the extension* where it helps, and *States · light & dark*.
  Save preview and Sync status show what was saved and whether it reached
  the library.
- **Extension** — surfaces built from those components: the Add details card,
  for every kind of save and sync state.
- **Web / Planned** — decided designs waiting for the website (the drafts
  banner above the library).

The toolbar's **Theme** switches light and dark; **Viewport** sizes the canvas;
the pseudo-state button forces hover, focus or pressed.

## Where it goes next

1. **Extension** — now: every extension surface on these components.
2. **App** — the Expo app adopts the same tokens and component names.
3. **Website and dashboard** — the Next.js site follows, and this Storybook
   grows an App and a Web section.
