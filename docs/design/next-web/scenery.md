# Foundkeep scenic artwork

Three original images were generated for this release with the image-generation tool. They were shown separately for review in the implementation thread. Each source is 1672×941; production uses self-hosted 800px and 1600px WebP variants. No third-party image service runs in the browser.

| Scene | Use | Asset prefix |
| --- | --- | --- |
| Alpine | Main hero and footer | `foundkeep-alpine-` |
| Stillwater | Collection illustration | `foundkeep-stillwater-` |
| Coastal | Closing invitation | `foundkeep-coastal-` |

The art direction asked for realistic landscapes with an uncluttered azure sky, natural mint accents, and quiet foreground detail. Alpine uses mountain ridges and a low cloud ribbon; Stillwater uses a reflective mountain lake; Coastal uses pale limestone, turquoise water and sage vegetation. No text, interface elements, logos, people or fabricated product screenshots were generated.

Motion is a separate interface layer: native smooth anchor scrolling, restrained landscape movement, one-time section reveals, and hover/focus feedback. Reduced-motion preferences disable travel and scroll animation. All content stays visible without JavaScript.
