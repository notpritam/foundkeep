Add Atlas to Chrome.
Your first collection starts with your next find.

Download Atlas Chrome extension · ZIP · manual installation

  1. Download and unzip.

    Extract the ZIP into a folder you can keep. Chrome will load the extension from that folder.

  2. Load it in Chrome.

    Open chrome://extensions, switch on Developer mode, then choose Load unpacked and select the extracted folder.

  3. Pin Atlas. Save something.

    Open Chrome’s extensions menu and pin Atlas. Try a screenshot, save a highlight, or write yourself a note.

A few useful details.

Where do my captures live?

Atlas stores captures in IndexedDB in the browser where you installed it. There is no automatic cloud sync. Optional enrichment sends content to your configured companion; its model provider may process that content remotely. Read about data handling.

Do I need an account or an AI companion?

You can capture, browse and search your local library without an account or a companion. A companion is optional and adds OCR, summaries and tags.

Can I use keyboard shortcuts?

Yes. The suggested shortcuts are Alt + Shift + S for a region screenshot, F instead of S for a full-page screenshot, and H for a highlight. Check or change assigned shortcuts at chrome://extensions/shortcuts; your browser or operating system may reserve some combinations.

How does optional browser control work?

Advanced setup can connect an external agent through a local bridge or hosted relay. You explicitly enable one tab; page context and actions can travel through that connection. This is separate from capture and is not needed to use your library. Read the setup guide, or redeem an existing relay invite.

Where can I get help or see the source?

Atlas is open source. Visit the GitHub repository for setup instructions, or open an issue to report a problem.
