Privacy & data.

Updated 6 September 2026

Your captures are stored in your browser. Optional enrichment and browser control create additional data flows, described below.

What you save

Atlas captures screenshots, highlighted text, bookmarks, images, tweets and notes when you use its capture actions. Saved items can include source context such as a page title, URL, favicon and capture time.

Your local library

Captures are stored in IndexedDB in the browser profile where Atlas is installed. Extension connection settings are stored in browser extension storage. You can save, browse and search captures without a companion. Atlas does not provide automatic cloud sync between your browsers or devices.

Optional enrichment

When an enrichment companion is configured and available, Atlas can send pending captures to it for OCR, summaries and tags. That content may include saved text, images and source metadata.

A companion running on your computer does not mean that all processing stays on your computer. Claude Code or another configured model service may send content to a remote model provider. The companion endpoint and model provider you use determine where that processing happens. Review their configuration and data handling before enabling enrichment for sensitive material.

Optional browser control

Browser control is separate from your capture library. An external agent can connect through a local bridge or a token-authenticated hosted relay. You explicitly enable control for one tab at a time.

When control is enabled, page context and requested browser actions can pass through the configured connection. A hosted relay carries this traffic between the extension and the external agent; the agent’s model provider may also process page context. Turn off control for the tab to revoke that access.

Browser permissions

  • Page access, tabs and scripting: support capturing page content, selecting regions and operating Atlas’s on-page controls. Browser restrictions can prevent capture on protected pages.
  • Storage: keeps extension settings locally; the capture library uses IndexedDB.
  • Context menus and alarms: provide right-click capture actions and scheduled extension work, including processing pending captures when a companion is available.
  • Debugger and connection access: support optional browser control and communication with the configured local bridge or hosted relay.

Deleting saved items

Delete captures from the Atlas library to remove them from its local collection. Removing the extension also removes its local extension data. Local deletion does not remove content already sent to a companion, relay, external agent or model provider; those systems have their own storage and deletion behavior.

Questions and source code

This page describes Atlas’s product data flows. For implementation details or questions, see the source repository or open an issue. Avoid posting private captures or connection tokens in public issues.
