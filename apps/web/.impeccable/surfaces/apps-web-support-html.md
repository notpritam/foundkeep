# Foundkeep customer support

## Scope and mode

Read mode for the public customer support route. This brief applies only to `support.html`; the Foundkeep system in the repository-root `DESIGN.md` remains authoritative for palette, type, controls, spacing character, and accessibility.

## Audience and job

Help a Foundkeep customer locate where installation, browser connection, capture, sync, account recovery, or settings behavior stopped, then complete the shortest safe recovery path. Keep local-first behavior, account boundaries, source retention, consent, and separate local/cloud deletion explicit wherever the advice depends on them.

## Content and action

Lead with the four-step Capture → Queue → Sync → Find route and five symptom links so readers can diagnose before reading. Follow with ordered, task-focused answers; use short inset notes for a consequential caveat or boundary. The primary action moves to symptom selection. The closing primary action opens the support email address, with the public issue tracker as a secondary destination and tells customers which diagnostic details to include and which private values to omit.

## Direction and memorable moment

Treat the page as an editorial field guide inside Foundkeep's white and scenic-blue web world. The first viewport pairs the direct “Help, from save to sync.” headline with the compact four-step route; that lifecycle diagram is the route's memorable diagnostic device. Fine rules, numbered steps, azure labels, and a sky closing panel extend established Foundkeep patterns without creating new global tokens or components.

## Responsive behavior

On wide screens, pair the introduction with the lifecycle route, show symptom links in two columns, and place answer headings beside their instructions. On narrow screens, preserve the same reading order in one column, hide the secondary library link in the header, stack the primary and secondary actions, and keep every support topic directly reachable without horizontal overflow.

## Constraints

- Support only shipped Foundkeep behavior and Chromium-family desktop installation; do not imply mobile-browser support, email password resets, remote-code updates, or automatic import of older local captures.
- Use plain recovery language and real destination links. Do not add promotional claims, testimonials, tracking, or speculative troubleshooting.
- Preserve keyboard navigation, visible focus, reduced-motion behavior, semantic heading order, and source-safe privacy guidance.

## Unresolved decisions

None for the shipped route.
